FAQ

Common questions

Still stuck? Report a bug.

  • What is the “external” section, and what should I do with it?

    From version 1.2, POPtime stores clips in local app storage instead of the photo gallery. Some operating systems used to offload videos to iCloud, which made clips vanish mid-session. The app now copies imported videos locally. If a clip still sits under External, it was already evicted to iCloud and the app cannot find the file on-device. Workaround: start adding a new video, pick that clip from the gallery, wait until “Downloading from iCloud” finishes, then cancel the picker and restart the app. Confirmation is not required — once the download completes, POPtime can copy it.

  • Why did my export overlay show the wrong exchange time?

    A known export path used to flip values (for example 0.6 reading as 1.4). Update to the latest App Store / Play build — overlay export and lock-screen interruptions were patched in 2.3–2.4. If it still happens, file a bug with a screenshot of the overlay and the two mark times.

  • The app asked for my whole photo library. Can I refuse?

    Yes. Current iOS builds only need the clip you pick, and export uses add-only permission. You do not have to grant full library access.

  • Subscription will not restore after reinstall.

    Use Restore Purchases in the paywall, signed in with the same Apple ID or Google account that bought Pro. If restore still fails, report it with the store receipt email and device.

  • Can I change overlay color and size?

    Overlay position is customizable in current builds. Timer color and scale are a frequent request — mention it on a report if the red-on-dark overlay is hard to read on your film.

  • Does POPtime work for softball, or only baseball?

    Both. Catchers on baseball and softball use the same marks — 1st catch, release, and 2nd catch. Throws to second or third both work. Velocity and pop assume a baseball path today; if you need a fastpitch-specific distance, mention it on a report.

  • Does POPtime work for pitchers?

    Yes. Version 2.1 added a pitcher mode with velocity tracking from the same clip, without a radar gun. Coach mode is a separate subscription tier with extra overlay controls. Pro also includes footwork tracking on the throw down.
